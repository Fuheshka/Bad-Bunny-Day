ЧАСТЬ 3: ПРОВЕРКА INPUTSYSTEM_ACTIONS
=========================================================================

Скрипт Stage 2 использует существующее действие Sprint для рывка (dash).
Нужно убедиться, что оно настроено правильно:

1. Откройте Assets/InputSystem_Actions.inputactions двойным кликом
2. В окне Input Actions смотрите Player ActionMap
3. Убедитесь, что существует действие "Sprint":
   - Type: Button (не Value)
   - Bindings включают:
     * Keyboard: Shift
     * Gamepad: Left Shoulder Button (LB/L1)

4. Если действие не настроено, добавьте:
   - Нажмите + рядом с Player ActionMap
   - Назовите действие "Sprint"
   - Установите Type = Button
   - Добавьте Binding для Shift
   - Добавьте Binding для Gamepad Left Shoulder

5. Сохраните InputSystem_Actions (Ctrl+S)

Действие Jump уже должно быть добавлено из Stage 1.

ЧАСТЬ 6: ТЕСТИРОВАНИЕ В ИГРЕ
=========================================================================

Запустите игру (Play в Unity):

1. БАЗОВОЕ ДВИЖЕНИЕ И СПРИНТ (проверьте, что Stage 1 работает):
   - Нажмите WASD - персонаж должен двигаться
   - Нажмите Shift + WASD - персонаж должен двигаться быстрее (спринт)
   - На геймпаде: левый стик для движения, LB для спринта
   - Персонаж должен плавно поворачиваться в сторону движения

2. ЭНЕРГИЯ (STAMINA):
   - Откройте Console (Window > General > Console)
   - Начните игру и смотрите Console
   - При движении в Console должны появляться сообщения о системах
   - Энергия должна регенерироваться автоматически

3. РЫВОК (DASH):
   
   Попытка 1 - Рывок с нормальной энергией:
   - Убедитесь, что вы не двигаетесь (энергия полна - 100)
   - Нажмите Shift один раз (без WASD)
   - Персонаж должен быстро рвануться вперед
   - Это должно быть очень быстрым движением (0.3 сек)
   - Энергия должна уменьшиться на 30
   - В Console должно появиться сообщение о Noise event

   Попытка 2 - Рывок в направлении движения:
   - Нажмите WASD для движения вперед
   - Нажмите Shift для рывка
   - Персонаж должен рвануться в направлении движения (вперед)
   - Энергия минус 30

   Попытка 3 - Откат после рывка:
   - После рывка подождите 0.5 сек (видимый откат в консоли)
   - Пока откат идет, рывок недоступен
   - После отката можно делать новый рывок (если энергия достаточна)

   Попытка 4 - Недостаточно энергии:
   - Делайте рывки подряд пока энергия не упадет ниже 30
   - Когда энергия < 30, рывок не должен срабатывать
   - Должно быть видно замедление в консоли
   - Подождите ~2.5 сек чтобы энергия восстановилась

4. СООБЩЕНИЯ В CONSOLE:
   Должны видны сообщения вроде:
   - "[Noise] Dash event at position (...) with priority 10"
   - Сообщения об инициализации систем на старте

ЧАСТЬ 7: ОТЛАДКА И РЕШЕНИЕ ПРОБЛЕМ
=========================================================================

ПРОБЛЕМА: Компоненты не добавились на Player при Play

РЕШЕНИЕ:
1. Убедитесь, что Player имеет тег "Player"
   - Выберите Player
   - В Inspector сверху видна строка Tag
   - Если там "Untagged", нажмите на Tag и выберите "Player"
   - Если "Player" не в списке, создайте новый tag "Player"
2. Убедитесь, что Rigidbody присутствует на Player
3. Нажмите Play еще раз
4. Если не помогло, смотрите Console на ошибки

ПРОБЛЕМА: "Could not find player GameObject with tag 'Player'"

РЕШЕНИЕ:
1. У объекта Player точно установлен тег "Player"?
2. Объект Player активен (чекбокс слева от имени включен)?
3. Нет других объектов с тегом "Player"?
4. Если ошибка остается, создайте нового пустого Player и сделайте его заново

ПРОБЛЕМА: "Player GameObject must have a Rigidbody component"

РЕШЕНИЕ:
1. Выберите Player
2. В Inspector нажмите "Add Component"
3. Ищите "Rigidbody" и добавьте её
4. Настройте параметры как в ЧАСТИ 5

ПРОБЛЕМА: Рывок не работает (нет ускорения при нажатии Shift)

РЕШЕНИЕ:
1. Проверьте, что у Player есть компонент PlayerInput
2. Убедитесь, что в PlayerInput установлен InputSystem_Actions
3. Откройте InputSystem_Actions и проверьте, что Sprint действие существует
4. Убедитесь, что Sprint привязан к Shift клавише
5. Проверьте Console на ошибки
6. Смотрите что в Console выводится при нажатии Shift

ПРОБЛЕМА: Рывок срабатывает но не быстро / не видно разницы

РЕШЕНИЕ:
1. Это может быть из-за высокого значения PlayerMovementDrag
2. Откройте GameConfig.cs
3. Уменьшите PlayerMovementDrag с 8 на 4-5 для более заметного эффекта
4. Или увеличьте PlayerDashSpeedMultiplier с 3 на 4-5
5. Сохраните и Play снова

ПРОБЛЕМА: Энергия не восстанавливается

РЕШЕНИЕ:
1. Убедитесь, что персонаж стоит на месте (не дует Shift)
2. Энергия восстанавливается только когда:
   - Не выполняется рывок (IsDashing = false)
   - Не выполняется спринт (IsSprinting = false)
3. Если спринтите Shift, энергия не восстанавливается
4. Отпустите Shift и подождите

ПРОБЛЕМА: Console полна красных ошибок

РЕШЕНИЕ:
1. Посмотрите первую красную ошибку (самую верхнюю)
2. Кликните на неё чтобы открить файл с ошибкой
3. Ошибка покажет номер строки и что не так
4. Общие ошибки:
   - Missing reference: скрипт не находит компонент
   - NullReferenceException: переменная не инициализирована
   - Type not found: забыли using statement

ЧАСТЬ 8: ОПТИМИЗАЦИЯ И НАСТРОЙКА
=========================================================================

После того как основной функционал работает, можно настроить параметры:

БЫСТРЕЕ / МЕДЛЕННЕЕ ЭНЕРГИЯ:
1. Откройте GameConfig.cs
2. Найдите PlayerStaminaRegenRate = 20f
3. Увеличьте для быстрой регенерации (30, 40, 50)
4. Уменьшите для медленной регенерации (10, 15)

БОЛЬШЕ / МЕНЬШЕ СТОИМОСТЬ РЫВКА:
1. PlayerDashStaminaCost = 30f (текущая стоимость)
2. PlayerDashStaminaThreshold = 30f (минимум для рывка)
3. Увеличьте Cost для дороже рывка
4. Уменьшите для дешевле рывка

БЫСТРЕЕ / МЕДЛЕННЕЕ РЫВОК:
1. PlayerDashDuration = 0.3f (как долго длится рывок)
   - Увеличьте (0.4, 0.5) для более долгого рывка
   - Уменьшите (0.2, 0.1) для очень быстрого рывка
2. PlayerDashSpeedMultiplier = 3f (множитель скорости)
   - Увеличьте (4, 5) для более быстрого рывка
   - Уменьшите (2, 2.5) для медленнее рывка

БОЛЬШЕ / МЕНЬШЕ ОТКАТ ПОСЛЕ РЫВКА:
1. PlayerDashCooldown = 0.5f (время ожидания перед следующим рывком)
2. Увеличьте для более длинного отката (0.7, 1.0)
3. Уменьшите для более быстрого отката (0.2, 0.3)

ЧАСТЬ 9: ПРОВЕРКА ШУМОВ (NOISE SYSTEM)
=========================================================================

Система шумов используется для алертирования врагов (их добавим позже).
Пока проверим что шумы генерируются правильно:

1. Запустите игру (Play)
2. Откройте Console (Window > General > Console)
3. Выполните рывок (нажмите Shift)
4. В Console должно появиться сообщение с информацией о шуме

Если сообщений нет:
1. Проверьте что NoiseGenerator.cs существует
2. Убедитесь что DashSystem вызывает GenerateNoise
3. Проверьте что нет ошибок в Console

Позже враги смогут подписаться на эти события и реагировать на шум.
